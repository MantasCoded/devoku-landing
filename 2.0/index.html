Job examples

Marketing

Run ad budgets by rules

  1. You set the rule: raise the budget when CPC drops to $0.15
  2. The agent watches the campaign around the clock
  3. It changes the budget and reports in chat

Sales

Quote from the price list

  1. A quote request lands in your sales inbox
  2. It reads the price list, then builds the quote
  3. Anything off the list is left out and reported

Engineering

Triage production errors

  1. Each hour it reads the new Sentry issues
  2. A known error gets a note on its GitHub issue
  3. A new one opens one issue with the stack trace

Finance

Enter supplier invoices

  1. Each hour it reads the invoices in the inbox
  2. It finds each one in Sage or Xero, or adds it
  3. A duplicate is skipped, an odd one is flagged

Operations

Read batch certificates

  1. It reads each batch certificate from goods-in
  2. Every result is checked against the spec
  3. A failing batch is held and the manager told
